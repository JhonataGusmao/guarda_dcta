Guarda DCTA

Sistema web desenvolvido para controle e gerenciamento de visitantes, com registro de entradas e saídas e geração de documentos em PDF.

O projeto foi desenvolvido em PHP + MySQL, utilizando uma interface web para organizar o fluxo de visitantes e facilitar a consulta dos registros.

Funcionalidades:

Cadastro e registro de visitantes

Controle de entrada e saída

Listagem e consulta de visitantes

Registro das movimentações
 
Geração de documentos/relatórios em PDF

Organização dos registros em tabelas

Identidade visual personalizada

Integração com banco de dados MySQL/MariaDB

Tecnologias utilizadas

PHP

MySQL / MariaDB

HTML5

CSS3

JavaScript

Composer

Dompdf

XAMPP para ambiente local

O Guarda DCTA foi desenvolvido para apoiar o controle de visitantes, centralizando os registros de entrada e saída e facilitando a consulta e emissão de documentos.
